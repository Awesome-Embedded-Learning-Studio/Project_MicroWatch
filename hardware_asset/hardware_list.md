# 小手表硬件清单

> Author: [HNHKHNH](https://github.com/HNHKHNH)

## 功能性部分

1. **主控芯片：STM32G431CBU6**（QFN-48裸片-11R）

   能微量采购到的最便宜的ST高性能QFN封装芯片，发布年份新，功能强大。

   日历功能使用芯片的RTC实现，减少器件数量。

2. **OLED屏幕：1.32寸128x96分辨率**（裸片-13.8R / 开发板-35R）

   常规工业黑白显示屏，选择了适合手表的尺寸（32.6*28.3mm）。

3. **陀螺仪：MPU6500六轴**（裸片-18.3R / 开发板-5.28R）

   老朋友，玩的多比较熟。裸片是MPU-6x或9x系列里最便宜的。

4. **按键：四脚拨轮U型按键**（裸片-0.9R）

   常见于小型mp3设备上，操控方便。

5. **直流振动马达**（裸片-1.07R）

   外径8mm圆形，控制简单，用于操作反馈。



## 基础性部分

1. **电池：3.7v聚合物电池302030，150mAh**（裸片-9.1R）

   常规聚合物电池，长宽（31*20mm）不超过屏幕的情况下容量尽可能大。

   后续容量不够可更换红米手表单芯470mAh电池。

2. **降压芯片：PW5410B**（裸片-0.3R）**或者PW2224**（裸片-0.7R）

   一些常用的LDO对于输入与输出电压的压差有要求，如：Vin-Vout≥1V。因此无法满足单芯电池3.7v降至3.3v的需求。

   因此选用电荷泵芯片，外围电路少（只需要几个电容），单个PW5410B输出电流100mA，能满足G431满频率下可能的最大电流（170MHz，125℃下44.0mA）。

   可采用多个PW5410B分别负责核心、各个传感器的方案，或者用一个PW2224（Vin>3.6V时有3.3V_3A的输出）管理所有电路的方案。后续会比较两种方案占用板面积大小，多降压方案优先（单寄不会全寄）。

3. **电池管理芯片：PW4054H**（裸片-0.18R）

   0.8A可编程充电电流，小体积，外围电路少，小板友好芯片。

4. **其他电路：**

   - 电源检测电路：电阻分压后用单路ADC采集
   - LED侧灯（电源指示和交互）

#### 后期升级选项：

1. 更换1.32寸466*466含触控的消费级OLED圆形屏幕。

2. 更大的单芯电池。

3. **增加小喇叭：圆形直径8mm-16Ω0.25W**（裸片-4.1R）

   音频播放需要额外的解码芯片和放大电路，可能会占用较多的电路板面积，并且我们也缺乏这方面的开发经验，可以看后续进度决定是否加入此功能。

4. **更换便宜且功能更多的陀螺仪：博世bmi160**（裸片-10R）

   功能强大且更贴合手表：内置单击检测（Tap Sensing）、计步（Step Counter）功能，数据直接存在陀螺仪的寄存器里。价格便宜，缺点是资料只有说明书。后期有余力可以玩。
