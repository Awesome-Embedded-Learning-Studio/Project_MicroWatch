# MicroWatch 功能清单

---

## 1. GUI 主控 + 按键交互

- **锁屏**：按键或抬腕亮屏/熄屏
- **滑动菜单**：支持左右滑动的菜单式界面（Icon + Text），与按键左右拨动语义一致
- **确认选择**：按下即选中，进入对应子菜单
- **App 显示框架**：为上层应用提供统一的显示与交互界面

## 2. IMU 传感器（MPU-6500）

- **计步器**：基于加速度数据的步数统计
- **水平仪（Fallback）**：利用姿态数据实现简易水平仪

## 3. 调试串口

- **运行时日志库**：提供轻量级日志输出，方便开发调试与问题排查

## 4. LED 指示

- **状态显示**：根据运行状态进行灯光反馈（具体方案随开发阶段细化）

## 5. 振动马达

- **步数提醒**：每 N×100 步触发一次短振动（与计步器联动）
- **闹钟震动**：定时闹钟触发震动提醒，支持震动模式

## 6. 电池电压检测

- **电量显示**：采集电池电压，通过 BatteryWidget 在界面上呈现剩余电量

## 7. 充电功率控制

- **充电状态反馈**：GUI 实时显示充电功率与充电状态

## 8. 小游戏

- **DinoGame**：内置 Chrome 恐龙跑酷小游戏
